# iOS map

Native SwiftUI iPhone app; iOS 17+, scheme `Gestiq` in `Gestiq.xcodeproj`. No third-party dependencies.

- `Gestiq/GestiqApp.swift`: owns observable session state; restores on launch, selects retry/login/authenticated screens and checks access expiry every minute while active.
- `Gestiq/Admin/AdminDetailView.swift`: `AuthenticatedRootView` adds Clients/Businesses tabs when login `user.role.pageRoles[].page.route` allows `/clients` or `/customers`; administrative Inicio requires admin role and `/dashboard`; Account always available. Native detail shows account/contact, booking summaries, five recent appointments, business policies/hours and saved payment linkage. Activation actions appear only in details (`AdminAccountActionView`), with confirmation. Role names are normalized (name/roleName); account status supports canonical and Spanish labels. Unknown roles/statuses hide actions. Server role/status checks remain authoritative. Company hours use Monday=0; no external links.
- `Gestiq/Admin/AdminDirectoryView.swift`: native searchable paginated lists (10 per page), detail navigation, pull-to-refresh, empty/error/retry states. Search capped at 100 characters, debounced 300 ms; changes reset page.
- `Gestiq/Admin/AdminModels.swift`: response DTOs for `GET /api/user/clients`, `/customers` and `/:id`; `{ data, pagination: { page, pageSize, totalItems, totalPages } }`. Generation guards ignore stale responses. Activation uses `DELETE /api/user/:id` (soft deactivation) and `PATCH /api/user/reactivate/:id`, requiring `{ data: true }`; reloads detail and increments session `adminRevision` to refresh directories/dashboard. Prevents duplicate/ineligible actions; reports ambiguous network failure without claiming success.
- `Gestiq/Admin/AdminDashboardModel.swift`, `AdminDashboardView.swift`: `GET /api/bookings/admin/statistics?month=YYYY-MM`; initial request omits month so backend uses business timezone. Current account/service totals, monthly booking outcomes and top five businesses link to native details. Month/year picker spans 2000–2099. Hides previous totals on reload, protects against stale periods, supports refresh/error/retry.
- `Gestiq/Views/LoginView.swift`: email/password form, loading and server errors. Matches web Login.scss brand colors/card layout; Arial uses the web fallback font with Dynamic Type. Login is the initial screen; no external navigation links. Registration, recovery and verification are outside the current app scope.
- `Gestiq/Assets.xcassets/BrandLogo.imageset`: logo copied from the web frontend's `src/assets/images/logo.png`; compiled through the target Resources phase.
- `Gestiq/Views/LoggedInView.swift`: native account screen with authenticated name/email, brand styling and confirmed logout.
- `Gestiq/Business/CompanyEditorView.swift`, `ServicesView.swift`: native business-owner tabs (`customer` role or non-admin `/services` permission). Create/edit business profile, location, photos, Monday=0 weekly hours and cancellation policies. Search/paginate/create/edit services with duration, discounts, retouch, advances, extras and photos; archive/publish only in detail with confirmation. Advance enabling requires the login user's saved Mercado Pago public key; payment linking is not included.
- `Gestiq/Business/BusinessModels.swift`, `BusinessState.swift`: GET `/company/myself` (only its explicit no-company 400 permits creation), POST/PATCH `/company`, GET/POST `/services`, GET/PATCH `/services/:id`, PATCH `/services/changeStatus/:id`. Decimal amounts accept strings/numbers. Existing hours/extras change via deletion plus insertion, matching backend behavior; unchanged service photos are omitted on update. Null prices clear disabled retouch/advance fields. Validate positive advance against all discounted modes, 1–5 active photos, maximum 5 image writes and 30 extra writes per request. Writes invalidate `businessRevision`; list generation guards ignore stale responses. Unknown network write outcomes require verification before retry.
- `CompanyEditorView.swift` also owns Profile/Hours/Policies sections, persistent save/error bar, native hour add/edit sheet and confirmed removal, numeric notice input, contextual guide, saved public-profile preview via GET `/company/:id` (including services), and native link/QR sharing for `https://gestiq.app/store/:id` using CoreImage. Preview does not open the website or submit reservations; sharing/copying remains user initiated.
- `Gestiq/Business/BusinessPhotos.swift`: PhotosPicker import, native previews and removal, normalized JPEG <=1600px and <1.5 MB each, raw base64 with filename/isNew. Existing photos retain file IDs for deletion. No web navigation or full photo-library access.
- `Gestiq/Auth/LoginModel.swift`: main-actor state, restore/retry, login/logout and shared renewal task. `authorizedData` supports GET/DELETE/PATCH/POST with optional JSON body and Bearer access, refreshes and retries once on 401 preserving the body. Temporary failures retain persistence; rejected refresh returns to login. Logout waits for ongoing renewal and blocks new renewals. `adminRevision` invalidates data after account status changes.
- `Gestiq/Auth/AuthClient.swift`: ephemeral URLSession without automatic cookie storage; `POST /api/auth/login` with `{ identifier, password }`, `/auth/refreshToken` and `/auth/logout`. Sends required Origin/session headers and saved refresh cookie. Response `{ data: { token, user } }`; saves rotated `gestiq_refresh` cookie from Set-Cookie. Access token/profile remain in memory.
- `Gestiq/Auth/KeychainSessionStore.swift`: refresh cookie and expiry in device-only Keychain, scoped to API URL. No credentials in UserDefaults or plain files.
- `Config/App.xcconfig`: public API URL and allowed web origin injected into `Gestiq/Info.plist`. Never put credentials here.
- `Tests/AuthClientChecks.swift`: mocked network/store checks for auth contract, restore, temporary failures/retry, logout and revocation; command in README. Does not access production or test real Keychain storage.
- `Tests/AdminChecks.swift`: mocked admin contracts, query encoding/pagination, permission gating/403, details/null metadata, 401 renewal/retry, out-of-order searches/periods, activation eligibility/endpoints/detail reload and dashboard contracts/errors; command in README. Does not change production accounts.
- `Tests/BusinessChecks.swift`: mocked business/service load/create/edit/status contracts, decimal decoding, hours/extras replacement, photo preservation/removal, pricing validation, explicit null resets, absent company vs outage and stale search protection; command in README. Does not change production data.

Build: `xcodebuild -project Gestiq.xcodeproj -scheme Gestiq -sdk iphonesimulator -configuration Debug CODE_SIGNING_ALLOWED=NO build`. Requires full Xcode; Command Line Tools alone cannot compile SwiftUI for iOS.
